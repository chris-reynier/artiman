ArtiMan – Mode d'emploi

Devis et factures pour artisans, sur votre PC. Gratuit, sans abonnement, sans Internet. Windows 10 et 11.

En bref : dézippez le dossier ArtiMan dans Documents, double-cliquez sur ArtiMan.exe, remplissez l'assistant de démarrage. Pour essayer d'abord sans rien saisir, double-cliquez sur Essayer la demo.cmd.

1. Installation

  1. Faites un clic droit sur le fichier ArtiMan-x.y.z.zip → Extraire tout…
  2. Choisissez un dossier à vous, par exemple Documents ou C:\ArtiMan.
    N'utilisez pas « C:\Program Files » : ArtiMan doit pouvoir écrire ses données à côté de lui.
  3. Ouvrez le dossier ArtiMan et double-cliquez sur ArtiMan.exe.
  4. Pour l'avoir sur le bureau : clic droit sur ArtiMan.exe → Afficher d'autres options → Envoyer vers → Bureau (créer un raccourci).
Premier lancement : Windows peut afficher « Windows a protégé votre ordinateur ». C'est normal pour un programme gratuit non signé. Cliquez sur Informations complémentaires puis Exécuter quand même. Cela ne se produit qu'une fois.

2. Découvrir avec la démo

Double-cliquez sur Essayer la demo.cmd : ArtiMan s'ouvre avec une entreprise, des clients, des devis et des factures fictifs. Un bandeau jaune « DÉMONSTRATION » le rappelle. Tout ce que vous faites en démo reste dans le dossier demo-data et ne touche jamais vos vraies données. Pour repartir d'une démo neuve, supprimez le dossier demo-data.

3. Le premier lancement : l'assistant

Au premier lancement de ArtiMan.exe, un assistant vous demande :

  • votre entreprise : nom, adresse, téléphone, SIRET, code APE, et votre logo si vous en avez un (sinon, le nom s'imprime en en-tête) ;
  • votre régime de TVA : vous facturez la TVA, ou vous êtes en franchise (micro-entreprise : « TVA non applicable, art. 293 B du CGI ») ;
  • votre assurance décennale, obligatoire sur les documents des artisans du bâtiment ;
  • la numérotation : première facture n°0001, ou la suite de vos factures existantes (la loi impose une numérotation sans trou) ;
  • un dossier de sauvegarde externe (clé USB ou OneDrive), conseillé.

Tout reste modifiable dans Paramètres. Vérifiez aussi les textes proposés pour le délai de paiement et les pénalités de retard (au besoin avec votre comptable), puis cochez Mentions vérifiées.

Reprendre vos clients

Si vos clients sont dans un tableau Excel, enregistrez-le en CSV (séparateur : point-virgule), puis dans Clients, cliquez sur Importer (CSV). La première ligne doit contenir les titres des colonnes : Nom, Prénom, Civilité, Adresse, Code postal, Ville, Téléphone, Portable, Email. Les clients déjà présents ne sont pas importés deux fois.

4. Le travail de tous les jours

Faire un devis

  1. Cliquez sur + Nouveau devis et choisissez le client (ou + Nouveau client).
  2. Saisissez les lignes : désignation (ex. MURS SALON), quantité, unité, prix unitaire, TVA, puis la description en dessous.
  3. Au clavier : Entrée passe au champ suivant, Ctrl+Entrée ajoute une nouvelle ligne. Le bouton 📚 ouvre la bibliothèque de descriptions : vos textes habituels, à réutiliser.
  4. + Section ajoute un titre (ex. SALLE DE BAINS). Glissez la poignée ⋮⋮ pour changer l'ordre des lignes.
  5. Cliquez sur Enregistrer (ou Ctrl+S). Le devis reçoit un numéro (ex. D2026-001).
  6. Aperçu / Imprimer pour imprimer, PDF pour obtenir un fichier à envoyer par email.

Le menu déroulant permet de noter si le devis est Envoyé, Accepté ou Refusé. Pour un travail semblable à un ancien, ouvrez l'ancien devis et cliquez sur Dupliquer.

Faire la facture

  1. Depuis le devis, cliquez sur Transformer en facture. Une facture brouillon est créée.
  2. Vérifiez-la, indiquez l'acompte déjà versé s'il y en a un, modifiez les lignes si les travaux ont changé.
  3. Cliquez sur Émettre la facture n°… : elle reçoit son numéro, un PDF est archivé automatiquement, et elle devient définitive.
  4. Quand le client a payé, ouvrez la facture et cliquez sur Marquer comme payée. ArtiMan n'enregistre pas les montants ni les moyens de paiement : seulement le statut « payée » ou « à encaisser ».
Pourquoi une facture émise n'est plus modifiable ? C'est une obligation légale : les factures doivent être numérotées sans trou et ne jamais être modifiées après envoi. En cas d'erreur, ouvrez la facture et cliquez sur Créer un avoir (il annule tout ou partie de la facture), puis refaites une facture correcte. Une facture sans devis se crée avec Factures → + Facture sans devis.

Retrouver un document

  • Accueil : factures à encaisser, devis en cours, chiffre d'affaires.
  • Clients : la fiche d'un client avec tous ses devis et factures.
  • Historique : recherche dans tous les documents, même dans le texte des lignes (ex. « lasure »), et export CSV pour le comptable.

5. Sauvegardes

ArtiMan sauvegarde tout seul : au démarrage, à la fermeture, à chaque facture émise et toutes les 6 heures. Les copies sont dans ArtiMan\data\backups.

Important : ces copies sont sur le même ordinateur. Si le disque tombe en panne, elles sont perdues. Indiquez une clé USB ou un dossier OneDrive dans Paramètres → Dossier de copie externe. ArtiMan y recopie chaque sauvegarde quand la clé est branchée, et affiche un rappel s'il n'a pas pu le faire depuis 7 jours.

Pour revenir en arrière : Sauvegardes → choisissez une date → Restaurer. L'état actuel est sauvegardé juste avant, rien n'est perdu.

6. Quitter, changer d'ordinateur

Fermez la fenêtre ou cliquez sur Quitter en bas à gauche : une sauvegarde est faite à la fermeture. Pour changer d'ordinateur, fermez ArtiMan, copiez tout le dossier ArtiMan (avec le sous-dossier data) sur une clé, et collez-le sur le nouvel ordinateur. Rien d'autre à installer.

7. Où sont mes fichiers ?

DossierContenu
data\artiman.dbLa base de données (clients, devis, factures)
data\documentsLes PDF des devis et factures émis (par année)
data\backupsLes sauvegardes automatiques
data\logsLe journal technique (en cas de problème)
demo-dataLes données fictives de la démo (peut être supprimé)

8. En cas de problème

ProblèmeSolution
« ArtiMan ne répond plus »Fermez la fenêtre et relancez ArtiMan.exe.
Rien ne s'ouvre au double-clicArtiMan est peut-être déjà ouvert : regardez la barre des tâches. Sinon, redémarrez l'ordinateur.
Les PDF ne se créent pasMicrosoft Edge doit être installé (il l'est sur tous les Windows 10 et 11). Vous pouvez toujours Imprimer puis choisir « Microsoft Print to PDF ».
Message rouge « base endommagée »Allez dans Sauvegardes et restaurez la dernière sauvegarde.

9. Mises à jour et aide

Les nouvelles versions sont publiées sur github.com/chris-reynier/artiman/releases. Pour mettre à jour : fermez ArtiMan, téléchargez le nouveau ZIP et remplacez uniquement ArtiMan.exe dans votre dossier. Le dossier data (vos clients, devis et factures) ne change pas.

Questions et idées : onglet Discussions. Ne publiez jamais de données de vos clients.

10. À savoir

ArtiMan est gratuit et fourni sans garantie (licence MIT, voir LICENCE.txt). Vous restez responsable de vos documents commerciaux : faites vérifier vos mentions légales (assurance, pénalités, TVA) par votre comptable.

Facturation électronique : à partir de septembre 2027, les factures entre professionnels devront être émises au format électronique via une plateforme agréée. ArtiMan convient aujourd'hui aux factures pour les particuliers ; l'export Factur-X est prévu avant cette échéance.
